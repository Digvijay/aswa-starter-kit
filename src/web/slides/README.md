# Slide deck

Reveal.js deck served by the Static Web App at `/slides` after deployment.

## Preview locally

Use the Static Web Apps CLI from the repository root:

```bash
swa start ./src/web --api-location ./src/api-node
```

Then open <http://localhost:4280/slides/>.

You can also open `index.html` directly in a browser if you only need to review the content.

## Keyboard shortcuts

- `S` — speaker notes
- `F` — fullscreen
- `?` — list all shortcuts
- `B` or `.` — black-out screen
